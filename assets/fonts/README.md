# Document font

`NotoSansArabic.ttf` is the unmodified Noto Sans Arabic variable font from the Google Fonts repository, retrieved on 2026-09-13:
https://github.com/google/fonts/tree/main/ofl/notosansarabic

SHA-256: `63111b5b2e074dd48cc67692e0a2726d86ee94c1c37fe8598257b7b4e87e869e`.

Copyright and SIL Open Font License 1.1 are preserved in `OFL-NotoSansArabic.txt`. The file ships with the application and is embedded as a subset by PDFKit; invoice and certificate rendering make no font download request. Latin and Arabic fixtures are covered, not every Unicode script.

PDFKit embedding reference: https://pdfkit.org/docs/text.html
Fontkit shaping reference: https://github.com/foliojs/fontkit
Bidirectional run ordering: https://github.com/lojjic/bidi-js
